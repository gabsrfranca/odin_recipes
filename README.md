# Odin Recipes

Um site simples de receitas criado como projeto de aprendizado do [The Odin Project](https://www.theodinproject.com/).

## Sobre o projeto

O projeto apresenta receitas em páginas próprias, com listas de ingredientes e instruções de preparo. A proposta é praticar a estruturação de páginas e a navegação usando HTML.

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador.

Ou

https://gabsrfranca.github.io/odin_recipes/

## Tecnologias

- HTML

## Aprendizados

- Estruturar páginas com elementos HTML;
- Criar links entre páginas;
- Organizar conteúdo em listas e seções.
